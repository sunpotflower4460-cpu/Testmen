# スタンプ習慣 🔴

継続したいことを登録して、**「本日できたか」だけ**に集中。
できた日はハンコをトンっと押して記録する、シンプルで気持ちいい習慣トラッカーです。

- ✅ **今日できたかだけ** — 迷わないワンタップ操作
- 🎯 **気持ちいいハンコ演出** — ばね・回転ブレ・波紋・インク飛沫＋効果音
- 📅 **カレンダー（縦：日付 × 横：タイトル）** — 一目で継続状況がわかるマトリクス
- 🔥 連続日数（ストリーク）・最長連続・月間合計を自動集計
- ↕️ タイトルの並び替え、絵柄・インク色の変更、削除に対応
- 💾 データは端末内（localStorage）に保存。エクスポート／インポート対応
- 📱 モバイルファースト。オフラインでも動作。`prefers-reduced-motion` 対応

## 使い方

1. 右下の **＋** から「継続したいこと」を登録（絵柄とインク色も選べます）
2. **今日**タブで、できたらハンコを押す
3. **カレンダー**タブで、日付 × タイトルの記録を確認（過去のセルをタップして追記も可）

## 開発

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をプレビュー
```

## 技術構成

- **React + TypeScript + Vite**
- 永続化：ブラウザの **localStorage**（バックエンド不要）
- アニメーション：**外部ライブラリ非依存**（純CSS ＋ JS生成パーティクル）
- 効果音：**WebAudio による合成音**（音声ファイル不要・消音可）

## データについて

記録はお使いのブラウザ内に保存されます。別の端末やブラウザには引き継がれないため、
バックアップや機種変更の際は **設定 → エクスポート** でJSONを保存し、
移行先で **インポート** してください。
